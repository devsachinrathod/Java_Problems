Fundamentals
Variables and Data Types
Variables store data values using assignment (e.g., x = 5). Python supports dynamic typing, automatically inferring types like integers (int: age = 25), floats (float: pi = 3.14), strings (str: name = "Alice"), booleans (bool: is_valid = True), lists (list: fruits = ["apple", "banana"]), tuples (tuple: point = (10, 20)), dictionaries (dict: person = {"name": "Bob", "age": 30}), and sets (set: unique = {1, 2, 3}).
​

Operators
Operators perform computations: arithmetic (+, -, *, /, //, %, ** as in result = 10 ** 2 yielding 100), comparison (==, !=, >, <), logical (and, or, not), assignment (=, +=), membership (in, not in), and identity (is, is not).
​

Control Structures
Conditional statements use if, elif, else:

text
if age >= 18:
    print("Adult")
else:
    print("Minor")
Loops include for (for i in range(5): print(i)) and while (count = 0; while count < 3: print(count); count += 1).
​

Functions
Define reusable code with def:

text
def greet(name):
    return f"Hello, {name}!"
print(greet("World"))  # Output: Hello, World!
Functions support parameters, returns, and defaults (e.g., def add(a, b=0): return a + b).
​

Key Practices
Use indentation for blocks (no braces). Comments start with #. Import modules like import math; print(math.sqrt(16)) for extended functionality.

python

python
